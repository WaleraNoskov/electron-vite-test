## Что из себя представляет
- Создано из шаблона (```npm create @quick-start/electron@latest my-app -- --template vue```).
- Представляет из себя React приложение, которое запускается в сервере Vite. За счет Electron запускается как оконное приложение (можно открыть инструменты отладки по F12).
- Используется библиотека контролов [Mantine](https://mantine.dev/core/package/) - очень популярное, кастомизируемое и открытое (MIT) решение.
- Реализуется подход [Future Sliced Design](https://feature-sliced.design/) *(на данный момент можно посмотреть features/detector-control)*.
- Пока не реализовано взаимодействие с бэкендом, т.к. его самого еще не существует

## Запуск
### Перед запуском
1. Установить Node.js и убедиться, что ```npm``` в консоли работает.
2. Открыть проект и выполнить ```npm i``` в корне.

### Запуск из консоли
В корне выполнить ```vite```.

### Запуск в JetBrains WebStormОткрываем в корне package.json, в блоке "scripts" будет строка "dev" - рядом с ней тыкаем на иконку запуска, конфигурация автоматически добавится в IDE.

## Соглашения
Пока нет какой-то определенной базы и дорожной карты, предлагаю создавать ветку для своих экспериментов и создавать PR в master. Позже можно создавать Issues, любые предложения по процессу обсудим вместе.
